# Week 7 Assignment - My Notes & The Report Builder

## Files Included
- **my_notes.py**: Script that writes, appends, reads, and counts lines in a text file.
- **my_notes.txt**: Text file generated by `my_notes.py` containing four notes.
- **report_builder.py**: Script that reads CSV data, processes scores, handles missing files, and writes a summary report.
- **hubs.csv**: CSV data file containing learner names, hubs, and scores.
- **report.txt**: Generated summary report containing learner totals, pass/fail counts, and average scores.

## Assignment Question
*What would happen if you changed `"a"` to `"w"` in Question 1?*

If you changed `"a"` (append mode) to `"w"` (write mode) when adding the fourth note, Python would truncate (erase) all existing content in `my_notes.txt` before writing.
